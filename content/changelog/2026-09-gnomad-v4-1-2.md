title: gnomAD v4.1.2
date: 2026-09-08

---

Today, we released gnomAD v4.1.2, a constraint-only update that corrects a bug in the v4.1.1 gene constraint metrics. In v4.1.1, transcripts with missing constraint values were included when computing ranks, which inflated the ranking denominator and shifted most transcripts into a lower bin. As a result, rank-based bin fields such as `lof.oe_ci.upper_bin_decile` were populated only for deciles 0-7, and the top bins were empty. v4.1.2 excludes transcripts with missing values from ranking, so all bins are now populated correctly. Note that the constraint metric values themselves (including LOEUF) are unchanged; only the rank and bin fields differ. All variant frequency data and filtering status are unchanged from v4.1.1.

<!-- end_excerpt -->

v4.1.2 updates only the files affected by the bug:

- gnomAD v4.1.2 gene constraint metrics Hail Table
- gnomAD v4.1.2 gene constraint metrics TSV

Any user working with these v4.1.1 constraint files should re-download the v4.1.2 versions from the [downloads page](https://gnomad.broadinstitute.org/downloads#v4-constraint).

All other v4.1.1 files, including the LOEUF percentile thresholds and the mutation and methylation rate files, were not affected by this bug and remain current at v4.1.1. Note that deciles computed by applying the LOEUF percentile thresholds may differ slightly from the bin columns in the constraint files; this is expected and unrelated to this bug. See the [constraint help page](https://gnomad.broadinstitute.org/help/constraint) for details.
